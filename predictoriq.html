PredictorIQ

Agent-powered analytics and decision support for prediction markets

PredictorIQ helps traders answer five practical questions: is the price justified, who is on each side, is behavior statistically unusual, how does pricing differ across venues, and what action is defensible right now.

What PredictorIQ Does (v0.2)

v0.2 is intentionally an "institutional-style" tool: it anchors pricing with real markets when possible, then adds wallet-level structure, anomaly context, and cross-venue comparison. It does not do subjective forecasting.

1) Option-Anchored Mispricing

Pricing anchor

For price-based events (above/below, touch, range), estimate a risk-neutral fair probability using option-implied volatility and payoff mapping (digital/barrier/range), then compare it to the market-implied probability.

Output: fair probability, implied probability, mispricing %, and cheap/fair/expensive verdict.

2) Yes/No Capital Structure

Who is on each side

Decompose each market by side: concentration (Top 1 / Top 10 / Top 1% / Top 10%), participant count, and wallet quality based on historical outcomes across prior markets.

Output: side-by-side "capital quality" comparison, not just volume.

3) Statistical Anomaly Context

Not accusations

Flag statistically unusual behavior (e.g., extreme position-size Z-scores, early favorable entries, new/low-history wallets, highly directional exposure). This is framed as contextual signal, not claims of wrongdoing.

Output: anomaly score, key contributing factors, and anomalous capital split by side.

4) Cross-Venue Price Comparison

Relative mispricing

Normalize economically equivalent events across venues and compare implied probabilities to highlight inconsistencies and potential arbitrage windows (subject to liquidity and settlement differences).

Output: cross-market gaps, execution considerations, and venue-specific caveats.

5) Explainable Recommendations (Professional-grade)

Decision support

Combine mispricing, capital structure, anomaly context, and liquidity into a defensible action: Buy Yes / Buy No / Avoid. Every output includes a short rationale identifying the dominant drivers (no black-box signals).

A working demo prototype is available for reviewers. View demo repository on GitHub .

Built on WAP3: Agent-to-Agent Trading, Escrow, Settlement

PredictorIQ is built on top of WAP3 — a programmable escrow and automatic settlement layer for AI agents. The goal is to make analytics and workflows tradable, verifiable, and fast enough to matter in live markets.

System Agents

Each core capability (mispricing scan, wallet quality, anomaly context, cross-venue gaps) is implemented as a specialized agent that continuously monitors markets and produces signed, attributable outputs.

User Agents

Each user can have a personal agent that requests signals, runs fast checks in a playground environment, and decides whether to purchase a specific analysis bundle or action plan.

Escrow & Settlement

WAP3 provides programmable escrow, rapid verification, and automatic settlement so agents can transact reliably under time pressure — where slow validation means missed edge.

Over time, the system accumulates a capability score for each system agent (how reliable and useful its outputs are) and a credit profile for each user agent (how it behaves in transactions). This creates a compounding trust and incentive layer for an agent-driven marketplace.

Note: all outputs are designed as decision support signals and statistical context; they are not guarantees and are not presented as financial advice.

How It Works (High Level)

v0.2 focuses on fast, explainable loops: detect → validate → act. In live markets, speed matters because the best edge is often purchased or arbitraged away quickly.

Step 1

Scan

System agents monitor markets across venues and compute candidate signals (mispricing, wallet structure, anomalies, cross-venue gaps).

Step 2

Package

Signals are packaged into auditable "analysis bundles" with provenance: inputs, assumptions, and explainable outputs.

Step 3

Test

User agents can quickly validate bundles in a playground using lightweight checks (e.g., sanity tests, sensitivity, venue constraints).

Step 4

Trade & Settle

If accepted, WAP3 handles escrow, settlement, and attribution, so both sides can transact with minimal friction.
